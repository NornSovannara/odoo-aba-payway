Introducing ABA PayWay for Odoo Point of Sale

Accept payments on Odoo Point of Sale with ABA KHQR, WeChat Pay or Alipay and get paid straight to your ABA Bank account.

How does it work?

How does it work?

1. Cashier takes the order

Cashier creates the order in Odoo Point Of Sale as they normally do.

2. Displaying payment QR on screen or printed bill

Cashier presses the button for a payment method like ABA KHQR, WeChat Pay, or Alipay to display the QR on the customer screen or print it on the bill.

3. Customer scans QR & pays

The customer pays from their Mobile banking app. The order updates to Paid in Odoo automatically.

How to install?

How to install?

Install the plugin

Install the ABA PayWay plugin from the Odoo App Store on Odoo 18.

Get Sandbox API key

Create a free PayWay Sandbox account to get your test API key.

Configure & Test

Paste your API key into the plugin in Odoo config, then run a test transaction.

Apply to go live

Contact our sales team to set up your ABA PayWay account and get paid.
